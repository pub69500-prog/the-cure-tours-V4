# Installation rapide sur GitHub

Remplace le contenu du dépôt par celui de ce ZIP, en conservant ton historique Git si tu le souhaites.

Le secret `SETLISTFM_API_KEY` reste nécessaire pour setlist.fm. Aucun secret n'est requis pour Cure Concerts Guide.

Après le premier déploiement, vérifie l'onglet **Actions** puis l'URL GitHub Pages. L'export Excel se trouve sur le site via le bouton **Excel**.
